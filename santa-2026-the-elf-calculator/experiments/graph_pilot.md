# 公开 baseline 计算图试验

输入：Hansen0223/Santa_2026 固定提交 0652a700 的根目录 submission.csv，SHA-256 `0f27cc12b9c6a59e7a61f2eaea9749e68b6d73601c599d8199d2db0761a57204`。程序来自第三方，使用前检查该版本的来源和许可。

运行（不需要原始比赛 CSV）：

```bash
python3 experiments/graph_pilot.py /path/to/submission.csv --id scored_0810
python3 experiments/graph_pilot.py /path/to/submission.csv --id scored_0001
```

输出每题的 baseline 和候选 DOT 图、JSON 报告及候选寄存器程序。可用 Graphviz 查看：`dot -Tsvg experiments/graph_scored_0810_baseline.dot -o /tmp/graph_0810.svg`。图中的每个指令节点代表寄存器的一个新版本；两条边指向实际读到的版本。黄色标示保守保护的数值，不代表该值一定是正式目标。

原始题目文件缺失。两个题的初值、上限来自本项目既有记录；正式目标集合没有完整保留。脚本将公开 baseline 和本项目此前记录为完整解的程序所产生的值集合取交集（含初值），作为保护集合：如果当时验证及记录无误，则它是正式目标集合的超集。这比只保护正式目标更保守，可能阻止有益改写。脚本校验完整候选程序覆盖这些值、寄存器和运算限制；**尚未用真实题目重新回放，不应视作正式有效性或提交结论**。

两题分别为 30、241 步。依赖裁剪后仍为 30、241 步。在每条指令前，枚举当前寄存器中的值，用一条四则运算重算同一结果，保留所有保护值，重新计算依赖并裁剪；贪心接受严格减少指令数的替换。两题都没有找到减少。另一项纯图探索针对保护值节点，尝试由任意两个更早产生的值一步计算，允许忽略寄存器生存期，重算依赖闭包，也没有得到正收益。这些结论仅限以上搜索范围；它不尝试多步新中间值、改变目标的首次命中节点、重排程序或多节点联合替换。

示例：0810 的 151050 由 570 × 265 产生，后面分别计算 151040 = 151050 − 10、151052 = 151050 + 2、151033 = 151050 − 17、151034 = 151050 − 16。它是多条路径的共享节点；这些黄色节点仅表示保护值，并非均为目标。简单删除其一条上游路径可能破坏其他下游分支，因此必须从所有必要输出反向取依赖闭包。

后续可以选择小块边界，列举一个或多个新中间值、同时替换多个输出，再重新计算并集成本；之后做寄存器分配和完整回放。这个问题更接近带 AND 运算节点的有向 Steiner/超图选择，普通最小割只能帮助识别边界或候选子图，不能单独求出最短合法算术程序。应使用真实目标及题目数据重新评估，并核算新增运算和寄存器压力。
